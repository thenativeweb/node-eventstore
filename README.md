# node-eventstore

> [!WARNING]
> **This project is no longer maintained.** It has been archived and will not receive any further updates, including security fixes.

If you're building event-sourced applications with Node.js, we recommend [EventSourcingDB](https://www.eventsourcingdb.io), a database built specifically for event sourcing, along with its [official JavaScript client](https://www.npmjs.com/package/eventsourcingdb). If you'd like help with the move, get in touch at [hello@thenativeweb.io](mailto:hello@thenativeweb.io).

node-eventstore was created by [Adriano Raiano](https://github.com/adrai), who maintained it from 2011 to 2020. Thank you, Adriano, and thanks to everyone who contributed.
